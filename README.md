# Steam Dashboard

Steamのプレイ履歴・実績・フレンドの遊びっぷりを可視化するWebダッシュボードです。個人開発の学習を兼ねて、React(Vite)+ Node.js/Express + Steam Web APIで構築しました。

## 作った理由

- SE(システムエンジニア)を目指す中で、企画から設計・実装・デプロイまで一人で通す経験を積みたかった
- ゲーム好きが高じて、自分のSteamライブラリを分析するツールが欲しかった
- Steam公式・非公式APIを組み合わせて外部サービス連携の実装力を身につけたかった

## 主な機能

### マイライブラリ
- 所持ゲーム一覧、プレイ時間順・名前順の並び替え、キーワード検索
- プレイ時間TOP10ランキング
- プレイ時間と実績解除率を組み合わせた独自の総合スコアランキング
- 積みゲー(未プレイゲーム)一覧と、ランダムに1本提案する「積みゲーガチャ」
- 直近2週間のプレイ状況から「最近よくプレイしているゲーム」を表示
- ウィッシュリストのセール情報をストア価格APIから取得して表示(クリックでストアへ)
- プレイ傾向から自動判定される称号バッジ(積みゲー王、実績マニアなど、16種類以上)
- 実績・プレイ傾向をもとにした画像シェア機能(匿名モード対応、X投稿・Discord向けクリップボードコピーに対応)
- 特定ゲームを一覧から非表示にできる管理機能

### フレンド
- フレンドの合計プレイ時間ランキング
- フレンドの「一番遊んでいるゲーム」「一番スコアが高いゲーム」「直近でよく遊んでいるゲーム」ランキング
- 自分とフレンドとのプレイ時間の差分を自動算出

### 認証・その他
- Steam OpenIDによるログイン機能(誰でも自分のアカウントでダッシュボードを利用可能)
- ダークモード/ライトモード切り替え
- 実績・フレンドデータの24時間キャッシュによる高速化

## 技術スタック

| 領域 | 技術 |
|---|---|
| フロントエンド | React(Vite) |
| バックエンド | Node.js, Express |
| 認証 | Passport.js(passport-steam) |
| 外部API | Steam Web API, Steam Storefront API |
| インフラ(想定) | Vercel(フロントエンド)+ Render/Railway(バックエンド) |

## 工夫した点

- **APIレート制限への対応**:実績データ取得など大量にリクエストが発生する処理は、リクエスト間隔を空けて順次処理することでSteam側の制限を回避
- **キャッシュ設計**:実績・フレンドデータをブラウザにキャッシュし、2回目以降のアクセスを高速化
- **プライバシー配慮**:シェア機能はSteamID等の個人情報を一切含めず、匿名モードもデフォルトで有効
- **段階的な機能拡張**:MVP(最小限の動くもの)から始め、ユーザー認証・キャッシュ・UIデザインまで段階的に改善
